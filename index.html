Let's talk

How this site works

This portfolio is built like a database, because that is what I build. Everything on it is real: the same facts, three ways to read them.

Three views

  • Easy-read is the whole profile as one plain page. Start here if databases are not your thing.
  • Schema draws each part of my profile as a table in a diagram. Dashed lines show how tables relate.
  • Table lets you pick any table and read it as a spreadsheet.

In the Schema view

  • Click a card’s header to open that table.
  • Drag the background to pan. Scroll or use − + to zoom. Click the percentage to fit everything.
  • Drag any card to rearrange it.

In an open table

  • Click a row to expand its details right under it. Click it again to collapse.
  • Click copy next to my email or links to copy them.

The query box

Ask the data a question in SQL. It is read-only, so nothing can break. Press Enter or Run. The three shortcut buttons above the box type a ready-made query for you.

Handy commands

\dt
list every table
\d projects
show a table’s columns
\theme dark
switch the colours (\theme light to switch back)
clear
close the results

Keyboard

/
jump to the query box
↑ ↓
step through your earlier queries
Tab
finish a table name or SQL word
Esc
clear the box, then close the results
